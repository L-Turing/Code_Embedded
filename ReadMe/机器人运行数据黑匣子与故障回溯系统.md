# 基于 RoboMaster A 型控制板的机器人运行数据黑匣子与故障回溯系统

## 项目背景

机器人在高速运动和复杂电磁环境下，可能出现姿态突变、传感器异常、CAN 通信超时、控制任务超时等问题。传统串口打印难以持续记录高频运行数据，也无法在系统复位或异常掉电后有效定位故障原因。

本项目基于 RoboMaster A 型控制板的 STM32F427、板载 MPU6600、MicroSD 卡槽、USB FS 和 CAN 接口，构建实时运行数据记录与故障回溯系统。系统持续采集姿态、系统任务、控制状态和 CAN 通信信息，在异常事件发生时保留故障前后关键数据，并通过 USB 和 Python 工具完成日志导出、校验与回放分析。

## 负责内容

- 基于 STM32F427 与 FreeRTOS 设计传感器采集、数据缓存、SD 卡写入、故障监测和 USB 通信多任务架构。
- 开发 MPU6600 的 SPI + DMA 数据采集模块，使用数据就绪中断触发读取，并通过硬件定时器提供统一时间戳。
- 开发基于 SDIO 四线模式和 FatFS 的数据记录模块，采用批量写入和环形缓冲机制，降低 SD 卡写入抖动对实时采集的影响。
- 设计含时间戳、序号、事件类型、长度和 CRC 校验的数据块格式，保证日志数据完整性与可追溯性。
- 实现 IMU 超时、CAN 通信超时、SD 卡写入失败、缓存溢出和任务超时等故障事件检测与记录。
- 实现循环日志和故障前后数据固化机制，支持系统复位后扫描并恢复最后一段有效日志。
- 基于 USB CDC 实现设备状态查看、参数配置和日志分块导出。
- 编写 Python 日志解析工具，实现 CRC 校验、姿态曲线绘制、任务运行时分析和故障事件回放。
- 设计连续运行、SD 卡拔插、异常复位和高负载场景测试，量化采样丢失率、写入时延和故障恢复能力。

## 技术难点

### 实时采集与 SD 卡写入冲突

SD 卡写入存在不可预测的长尾延迟。若采集任务直接调用文件系统写入，可能导致 IMU 数据丢失或控制周期抖动。通过 SPI-DMA、环形缓冲区和独立日志任务实现采集与写盘解耦。

### 异常掉电后的数据恢复

异常复位可能导致最后一个数据块未完整写入。通过预分配循环日志文件、固定格式数据块、递增序号和 CRC 校验，在系统重启后扫描并定位最后一个完整有效数据块。

### 多源数据时序一致性

IMU、CAN 状态、控制状态和任务事件来自不同任务及中断上下文。系统基于统一硬件定时器生成微秒级时间戳，并在日志中记录数据源和事件类型，保证离线回放时的时序一致性。

### 故障可诊断性

系统不仅记录原始传感器数据，还记录任务执行时间、缓存水位、外设错误码和故障事件。通过事件码和状态快照，将系统异常转化为可复现、可分析的故障证据。

## 实现方法与流程

```text
MPU6600 数据就绪中断
        ↓
SPI5 + DMA 读取原始 IMU 数据
        ↓
附加统一时间戳并写入采集缓冲区
        ↓
FreeRTOS 队列或环形缓冲区
        ↓
日志任务聚合 IMU、CAN、任务状态和故障事件
        ↓
封装为带序号、长度和 CRC 的二进制数据块
        ↓
SDIO + DMA 批量写入预分配循环日志文件
        ↓
USB CDC 查询、事件通知和日志分块导出
        ↓
Python 校验、解析、可视化和故障回放
```

## 开发计划

### 第一阶段：传感器采集与时间基准

- 完成 MPU6600 初始化、SPI-DMA 数据读取和中断处理。
- 使用硬件定时器生成统一时间戳。
- 通过串口输出验证采样频率、数据正确性和中断响应时间。

### 第二阶段：SD 卡记录与缓存设计

- 完成 SDIO 四线模式和 FatFS 文件系统驱动。
- 设计二进制日志数据块格式及 CRC 校验。
- 完成环形缓冲区、批量写入和循环文件机制。
- 测量不同写入块大小下的平均与最大写入时延。

### 第三阶段：故障回溯与可靠性机制

- 实现传感器超时、CAN 超时、缓存溢出和写卡失败检测。
- 实现异常事件触发、故障前后数据固化和重启恢复。
- 模拟 SD 卡拔插、异常复位和高负载场景，验证系统恢复逻辑。

### 第四阶段：日志导出与分析工具

- 完成 USB CDC 控制协议和日志分块导出。
- 编写 Python 日志解析与 CRC 校验工具。
- 实现姿态曲线、任务时延、缓存水位和故障事件可视化。
- 输出测试报告、系统架构图、演示视频和 GitHub README。

## 验收指标

- 在目标采样频率下连续运行，记录实际丢包率和最大采样间隔。
- 统计 SD 卡平均写入时延、最大写入时延和缓存最高水位。
- 验证 SD 卡拔出、异常复位和传感器超时后的故障检测与恢复结果。
- 验证日志解析工具可正确完成 CRC 校验、时间序列重建和故障事件定位。
